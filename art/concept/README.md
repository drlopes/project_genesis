# Concept art

Our own concept art, stored with Git LFS (see [../README.md](../README.md)).

## Layout

One folder per subject; create them as needed:

| Folder | For |
|---|---|
| `worlds/` | whole-planet looks, from orbit and on the surface |
| `biomes/` | biome and ecotone looks, palettes |
| `aquatic/` | underwater environments, benthic and pelagic |
| `flora/`, `fauna/` | living things |
| `structures/` | ruins, settlements, bases, POIs |
| `ships/`, `vehicles/` | craft and machines |
| `characters/` | player, NPCs, suits |
| `ui/` | interface and HUD |
| `mood/` | colour scripts, lighting, atmosphere studies |

## Naming

`<subject>_<short-name>_v<NN>.<ext>`, lowercase with hyphens inside the parts, e.g.
`biomes_temperate-forest-edge_v02.png`. Keep the working file (`.psd`, `.kra`, `.blend`) next to
its export with the same base name.

## Index

Every piece gets a row in [INDEX.md](INDEX.md): what it shows, author, date, rights, and the docs
it relates to (a biome in docs/07, an aquatic zone in docs/15, …). The index is what makes art
findable and useful as a reference.
