# Library (local only)

Raw research material: PDFs, saved articles, downloaded videos, cloned example code.

**Nothing in this folder except this README is committed.** It is ignored by git and excluded from
VS Code search and indexing. Name files after their source card: `<card-id>.<ext>`, or a folder
`<card-id>/` for cloned repositories. See [../README.md](../README.md).

Back this folder up separately; it is not on GitHub.
